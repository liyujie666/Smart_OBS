## 5. AMF0数据编码

### 5.1 AMF0概述

**AMF0 (Action Message Format 0)** 是Adobe的二进制序列化格式，用于RTMP命令和元数据的编码。

**特点**:
- 类型标记 + 数据，每个值以1字节类型标记开头
- 支持嵌套对象
- 大端字节序

---

### 5.2 AMF0数据类型详解

#### Number (0x00) — 8字节 IEEE 754 双精度浮点

```
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
|  0x00  |                    value (8 bytes, big endian)                         |
+--------+--------+--------+--------+--------+--------+--------+--------+--------+
```

**示例** (编码数字 1.0 = 0x3FF0000000000000):

```
0x00  0x3F 0xF0 0x00 0x00 0x00 0x00 0x00 0x00
type  |<------------- 8 bytes double ----------->|
```

---

#### Boolean (0x01) — 1字节

```
+--------+--------+
|  0x01  |  value |
+--------+--------+
           0x00=false, 0x01=true
```

---

#### String (0x02) — 2字节长度 + UTF-8数据

```
+--------+--------+--------+--------+--------+--------+
|  0x02  |  length (2B, BE)|       UTF-8 string        |
+--------+--------+--------+--------+--------+--------+
```

**示例** (编码字符串 "live"):

```
0x02  0x00 0x04  0x6C 0x69 0x76 0x65
type  |len=4|    'l'  'i'  'v'  'e'
```

---

#### Object (0x03) — 键值对集合

Object 由若干键值对组成，以 `0x00 0x00 0x09` 结束标记终止。

**注意**: key 没有类型标记，只有 2字节长度 + 字符串；value 是完整的 AMF0 值（含类型标记）。

```
+--------+
|  0x03  |  Object marker
+--------+
+--------+--------+--------+--------+
| key_len (2B, BE)|    key string    |  ← key，无类型标记
+--------+--------+--------+--------+
| type   |       value data          |  ← value，含类型标记
+--------+--------+--------+--------+
  ... 更多键值对 ...
+--------+--------+--------+
|  0x00  |  0x00  |  0x09  |  Object End Marker
+--------+--------+--------+
```

**示例** (编码 `{app: "live"}`):

```
0x03                        // Object marker
  0x00 0x03                 // key length = 3
  0x61 0x70 0x70            // key = "app"
  0x02                      // value type = String
  0x00 0x04                 // value length = 4
  0x6C 0x69 0x76 0x65       // value = "live"
0x00 0x00 0x09              // Object End Marker
```

---

#### Null (0x05) — 无数据

```
+--------+
|  0x05  |
+--------+
```

---

#### ECMA Array (0x08) — 带计数的键值对集合

与 Object 相同，但前面多4字节的元素计数（可以不准确，以结束标记为准）。

```
+--------+--------+--------+--------+--------+
|  0x08  |        count (4B, BE)              |
+--------+--------+--------+--------+--------+
+--------+--------+--------+--------+
| key_len (2B, BE)|    key string    |
+--------+--------+--------+--------+
| type   |       value data          |
+--------+--------+--------+--------+
  ... 更多键值对 ...
+--------+--------+--------+
|  0x00  |  0x00  |  0x09  |  Array End Marker
+--------+--------+--------+
```

---

### 5.3 AMF0编码实现

你的SDK中 `amf0.cpp` 的实现:

```cpp
void Amf0Value::encode(ByteBuffer& out) const {
    switch (type_) {
    case Type::Number:
        out.writeU8(0x00);
        out.writeF64BE(number_);
        break;
    case Type::Boolean:
        out.writeU8(0x01);
        out.writeU8(bool_ ? 0x01 : 0x00);
        break;
    case Type::String:
        out.writeU8(0x02);
        out.writeU16BE(string_.size());
        out.write((const uint8_t*)string_.data(), string_.size());
        break;
    case Type::Object:
        out.writeU8(0x03);
        for (const auto& [key, value] : members_) {
            out.writeU16BE(key.size());
            out.write((const uint8_t*)key.data(), key.size());
            value.encode(out);
        }
        out.writeU16BE(0);
        out.writeU8(0x09);
        break;
    case Type::Null:
        out.writeU8(0x05);
        break;
    case Type::EcmaArray:
        out.writeU8(0x08);
        out.writeU32BE(members_.size());
        for (const auto& [key, value] : members_) {
            out.writeU16BE(key.size());
            out.write((const uint8_t*)key.data(), key.size());
            value.encode(out);
        }
        out.writeU16BE(0);
        out.writeU8(0x09);
        break;
    }
}
```

### 5.4 构造RTMP命令示例

**connect 命令的完整 AMF0 编码**:

```
[String] "connect"          → 0x02 0x00 0x07 "connect"
[Number] 1.0 (txID)         → 0x00 0x3F 0xF0 ...
[Object] {                  → 0x03
  app:      "live"          →   0x00 0x03 "app"  0x02 0x00 0x04 "live"
  tcUrl:    "rtmp://..."    →   0x00 0x05 "tcUrl" 0x02 ...
  flashVer: "FMLE/3.0"     →   0x00 0x08 "flashVer" 0x02 ...
}                           → 0x00 0x00 0x09
```

**代码**:

```cpp
ByteBuffer buf;
Amf0Value::string("connect").encode(buf);
Amf0Value::number(1.0).encode(buf);

Amf0Value cmd = Amf0Value::object();
cmd.set("app",      Amf0Value::string("live"));
cmd.set("tcUrl",    Amf0Value::string("rtmp://server:1935/live"));
cmd.set("flashVer", Amf0Value::string("FMLE/3.0"));
cmd.set("type",     Amf0Value::string("nonprivate"));
cmd.encode(buf);
// buf 即为 Command Message 的 payload
```
