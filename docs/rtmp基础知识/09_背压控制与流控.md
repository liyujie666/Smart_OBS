## 9. 背压控制与流控

### 9.1 背压问题分析

**背压 (Backpressure)** 是指下游处理速度跟不上上游生产速度，导致数据积压。

#### 推流场景的背压源

```
编码器 ──► 推流队列 ──► 网络发送 ──► 服务器
 (固定)      (缓冲)      (可变)      (处理)
 30fps                  受带宽限制
```

**问题**:
1. **网络慢**: 上行带宽不足，发送缓冲区满
2. **服务器慢**: 服务器处理慢，TCP窗口收缩
3. **编码快**: 编码器固定30fps产生数据，不能停

**后果**:
- 队列持续增长 → 内存占用增加
- 延迟累积 → 直播延迟从3秒增长到10秒甚至更高
- OOM风险 → 长时间积压可能耗尽内存

### 9.2 队列延迟测量

```cpp
class BoundedQueue {
    struct QueuedSample {
        MediaSample sample;
        int64_t enqueueTimeUs;
    };

    std::deque<QueuedSample> queue_;

public:
    int64_t getDelayUs() const {
        if (queue_.empty()) return 0;
        // 队首元素的等待时间
        return getCurrentTimeUs() - queue_.front().enqueueTimeUs;
    }

    int64_t getMediaDelayUs() const {
        if (queue_.empty()) return 0;
        // 队首到队尾的媒体时间跨度
        int64_t headDts = queue_.front().sample.dtsUs;
        int64_t tailDts = queue_.back().sample.dtsUs;
        return tailDts - headDts;
    }
};
```

**两种延迟**:
- **墙上时钟延迟**: 数据在队列中等待的真实时间
- **媒体时间延迟**: 队列中数据的时间戳跨度（更准确反映直播延迟）

### 9.3 分层队列架构

你的SDK使用分离的音视频队列(`bounded_queue.h`):

```cpp
class DualQueue {
    BoundedQueue videoQueue_;
    BoundedQueue audioQueue_;
    PublisherConfig config_;

public:
    bool pushVideo(const MediaSample& sample) {
        int64_t delayMs = videoQueue_.getMediaDelayUs() / 1000;
        if (delayMs > config_.maxQueueDelayMs) {
            if (dropOldestGop()) {
                stats_.gopDropped++;
                requestKeyframe();
            }
        }
        return videoQueue_.push(sample);
    }

    bool pushAudio(const MediaSample& sample) {
        int64_t delayMs = audioQueue_.getMediaDelayUs() / 1000;
        if (delayMs > config_.maxAudioQueueMs) {
            audioQueue_.popFront();  // 丢弃最旧的音频帧
        }
        return audioQueue_.push(sample);
    }
};
```

**设计意图**:
- 音频和视频分开管理，互不干扰
- 视频可以丢整个GOP，音频丢单帧
- 避免视频积压影响音频实时性

### 9.4 GOP感知丢帧策略

#### 为什么要按GOP丢帧

直接丢单帧会导致解码器参考帧缺失，产生花屏：

```
丢单帧 (错误):
IDR P P [丢P] P P IDR ...
              ↑ 后续P帧参考了被丢的帧 → 花屏

丢整个GOP (正确):
[IDR P P P P] IDR P P P ...
 ↑ 整个GOP丢弃  ↑ 从新IDR开始，解码正常
```

#### GOP边界检测实现

```cpp
struct GOP {
    std::vector<MediaSample> frames;
    int64_t startDts = 0;
    int64_t endDts = 0;
    bool complete = false;
};

class GopQueue {
    std::deque<GOP> gops_;
    GOP currentGop_;

public:
    void push(const MediaSample& sample) {
        if (sample.type == SampleType::VideoKey) {
            if (!currentGop_.frames.empty()) {
                currentGop_.complete = true;
                currentGop_.endDts = currentGop_.frames.back().dtsUs;
                gops_.push_back(std::move(currentGop_));
            }
            currentGop_ = GOP();
            currentGop_.startDts = sample.dtsUs;
        }
        currentGop_.frames.push_back(sample);
    }

    bool dropOldestGop() {
        if (gops_.empty()) return false;
        GOP& oldest = gops_.front();
        LOG_WARN("Dropping GOP: {} frames, {}ms",
                 oldest.frames.size(),
                 (oldest.endDts - oldest.startDts) / 1000);
        gops_.pop_front();
        return true;
    }

    int64_t getTotalDelayMs() const {
        if (gops_.empty() && currentGop_.frames.empty()) return 0;
        int64_t startDts = gops_.empty() ?
            currentGop_.startDts : gops_.front().startDts;
        int64_t endDts = currentGop_.frames.empty() ?
            gops_.back().endDts : currentGop_.frames.back().dtsUs;
        return (endDts - startDts) / 1000;
    }
};
```

#### 三档阈值策略

对应你的SDK配置(`PublisherConfig`):

```
maxQueueDelayMs    = 800ms   → 中度积压，降码率
dropGopThresholdMs = 1200ms  → 严重积压，丢GOP
```

```cpp
void handleBackpressure() {
    int64_t delayMs = gopQueue_.getTotalDelayMs();

    if (delayMs > config_.dropGopThresholdMs) {
        // 严重积压：丢弃最旧的完整GOP
        if (gopQueue_.dropOldestGop()) {
            stats_.gopDropped++;
            requestKeyframe();
        }
    } else if (delayMs > config_.maxQueueDelayMs) {
        // 中度积压：请求降低码率
        int targetBps = currentBps_ * 0.8;
        if (bitrateCallback_) bitrateCallback_(targetBps);
    } else if (delayMs < config_.maxQueueDelayMs / 2) {
        // 恢复正常：尝试提升码率
        int targetBps = std::min((int)(currentBps_ * 1.1), maxBps_);
        if (bitrateCallback_) bitrateCallback_(targetBps);
    }
}
```

#### 请求频率限制

避免频繁请求导致码率波动:

```cpp
class KeyframeRequestLimiter {
    std::chrono::steady_clock::time_point lastRequestTime_;
    int minIntervalMs_ = 2000;  // 最小间隔2秒

public:
    bool tryRequest() {
        auto now = std::chrono::steady_clock::now();
        auto elapsed = std::chrono::duration_cast<std::chrono::milliseconds>(
            now - lastRequestTime_).count();
        if (elapsed < minIntervalMs_) return false;
        lastRequestTime_ = now;
        return true;
    }
};

void requestKeyframe() {
    if (!keyframeLimiter_.tryRequest()) return;
    LOG_INFO("Requesting keyframe");
    if (keyframeCallback_) keyframeCallback_();
}
```

### 9.6 动态码率自适应

#### EWMA带宽估计

你的SDK中`ewma.h`实现指数加权移动平均，用于平滑带宽估计:

```cpp
template<typename T>
class EWMA {
    T value_;
    double alpha_;
    bool initialized_ = false;

public:
    explicit EWMA(double alpha = 0.1) : alpha_(alpha), value_(T{}) {}

    void update(T newValue) {
        if (!initialized_) {
            value_ = newValue;
            initialized_ = true;
        } else {
            // 新值权重alpha，历史值权重(1-alpha)
            value_ = alpha_ * newValue + (1.0 - alpha_) * value_;
        }
    }

    T get() const { return value_; }
    void reset() { initialized_ = false; }
};
```

**alpha参数选择**:

| alpha | 响应速度 | 平滑程度 | 适用场景 |
|-------|----------|----------|----------|
| 0.1 | 慢 | 高 | 稳定网络 |
| 0.3 | 中 | 中 | 推荐默认 |
| 0.5 | 快 | 低 | 波动网络 |

#### 码率调整策略

```cpp
class BitrateController {
    EWMA<double> smoothedBps_{0.3};
    int currentBitrate_ = 0;
    int targetBitrate_ = 0;

public:
    void onBytesSent(int64_t bytes, int64_t nowUs) {
        double bps = computeInstantBps(bytes, nowUs);
        smoothedBps_.update(bps);

        int estimatedBps = static_cast<int>(smoothedBps_.get());
        int safeBps = estimatedBps * 0.8;  // 保守使用80%

        if (currentBitrate_ > safeBps * 1.2) {
            adjustBitrate(safeBps);  // 降低码率
        } else if (currentBitrate_ < safeBps * 0.8 &&
                   currentBitrate_ < targetBitrate_) {
            adjustBitrate(std::min(safeBps, targetBitrate_));  // 提升码率
        }
    }

    void adjustBitrate(int newBitrate) {
        if (newBitrate == currentBitrate_) return;
        LOG_INFO("Bitrate: {} -> {} bps", currentBitrate_, newBitrate);
        currentBitrate_ = newBitrate;
        if (bitrateCallback_) bitrateCallback_(newBitrate);
    }
};
```

### 9.7 RTMP Acknowledgement机制

RTMP协议要求客户端定期发送ACK，告知服务器已收到的字节数:

```cpp
class AcknowledgementTracker {
    int64_t bytesReceived_ = 0;
    int64_t lastAckBytes_ = 0;
    int32_t windowSize_ = 2500000;  // 服务器设置的窗口大小

public:
    void onBytesReceived(size_t bytes) { bytesReceived_ += bytes; }

    void setWindowSize(int32_t size) {
        windowSize_ = size;
        LOG_INFO("ACK window size: {}", size);
    }

    bool shouldSendAck() const {
        return (bytesReceived_ - lastAckBytes_) >= windowSize_;
    }

    void sendAck(ByteBuffer& out) {
        // Message Type 3: Acknowledgement
        RtmpMessage msg;
        msg.typeId = MessageType::Acknowledgement;
        msg.csid = 2;
        msg.streamId = 0;

        ByteBuffer payload;
        payload.writeU32BE(static_cast<uint32_t>(bytesReceived_));
        msg.payload = payload.data();

        chunkWriter_.write(msg, out);
        lastAckBytes_ = bytesReceived_;
        LOG_DEBUG("Sent ACK: {} bytes", bytesReceived_);
    }
};

// 在接收循环中
void Session::pumpRead() {
    uint8_t buffer[8192];
    int received = transport_->recv(buffer, sizeof(buffer));
    if (received > 0) {
        ackTracker_.onBytesReceived(received);
        inBuffer_.append(buffer, received);

        if (ackTracker_.shouldSendAck()) {
            ackTracker_.sendAck(outBuffer_);
        }
    }
}
```

#### Set Peer Bandwidth处理

服务器可以限制客户端发送速率:

```cpp
void Session::onSetPeerBandwidth(const RtmpMessage& msg) {
    if (msg.payload.size() < 5) return;

    uint32_t bandwidth = readU32BE(msg.payload.data());
    uint8_t limitType = msg.payload[4];

    // Limit Type: 0=Hard, 1=Soft, 2=Dynamic
    LOG_INFO("Server set peer bandwidth: {} bytes/s, type={}", bandwidth, limitType);

    if (limitType == 0) {
        maxSendRate_ = bandwidth;  // 硬限制，必须遵守
    } else if (limitType == 1) {
        maxSendRate_ = std::min(maxSendRate_, bandwidth);  // 软限制
    }
}
```
