## 使用说明

### 阅读顺序

**初学者推荐顺序**：
1. 第1章 → 第2章 → 第6章（了解协议和传输基础）
2. 第3章 → 第4章 → 第5章（了解编码格式）
3. 第7章 → 第8章（了解同步和状态管理）

## 配套源码

章节中的所有代码示例都来自SDK实际实现，对应源码路径：

```
librtmp_push/
├── include/rtmp/         # 公共头文件
│   ├── publisher.h       # 主要API
│   ├── types.h          # 类型定义（第7章、第8章）
│   ├── stats.h          # 统计信息（第10章）
│   └── capi.h           # C接口
├── src/core/            # 核心逻辑
│   ├── publisher_impl.cpp # 发布器实现（第8章）
│   ├── session.cpp       # 会话管理（第1章、第8章）
│   ├── bounded_queue.cpp # 队列管理（第9章）
│   └── metrics.cpp       # 统计监控（第10章）
├── src/protocol/        # 协议层
│   ├── handshake.cpp     # 握手（第1章）
│   ├── chunk_reader.cpp  # Chunk读取（第1章）
│   ├── chunk_writer.cpp  # Chunk写入（第1章）
│   ├── amf0.cpp         # AMF0编码（第5章）
│   ├── flv_tag.cpp      # FLV封装（第2章）
│   └── rtmp_message.h   # 消息定义（第1章）
├── src/transport/       # 传输层
│   └── tcp_transport_select.cpp # 网络IO（第6章）
└── src/util/           # 工具类
    ├── ewma.h          # 平滑滤波（第9章）
    └── logger.cpp      # 日志（第10章）
```

## 学习建议

1. **边读边调试**：对照源码单步调试，观察协议交互过程
2. **动手实践**：修改配置参数，观察行为变化
3. **抓包分析**：使用Wireshark抓取RTMP流量，验证理解
4. **异常测试**：模拟网络问题，测试容错机制
5. **性能优化**：根据场景调整参数，优化性能
